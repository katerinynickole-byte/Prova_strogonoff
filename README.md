# 🍽️ Site sobre Strogonoff

## 📖 Sobre o projeto

Este projeto foi desenvolvido como uma atividade prática de HTML5, com o objetivo de colocar em prática diferentes elementos e recursos da linguagem HTML.

O tema escolhido para o site foi o **strogonoff**, apresentando informações sobre o prato, sua origem russa, sua adaptação no Brasil e algumas características da receita tradicional.

Além do conteúdo informativo, o projeto também apresenta elementos de formulários e recursos multimídia, como imagem, vídeo e áudio.

O site é composto por **três páginas HTML**, conectadas por meio de um menu de navegação.

---

## 📄 Estrutura das páginas

### 🏠 Página 1 — Apresentação do Strogonoff

A primeira página apresenta uma introdução sobre o strogonoff e sua adaptação para a culinária brasileira.

Nela são apresentados:

- Uma breve descrição do prato;
- Informações sobre sua adaptação no Brasil;
- Imagem de um strogonoff brasileiro;
- Uma descrição da receita tradicional russa;
- Elementos de destaque e formatação de texto.

---

### 📜 Página 2 — História e origem

A segunda página apresenta informações sobre a origem histórica do strogonoff.

O conteúdo aborda:

- A origem do prato na Rússia;
- A família Stroganov;
- A relação entre a culinária russa e a influência francesa;
- Características da receita original;
- Ingredientes utilizados na versão tradicional;
- Diferenças entre o strogonoff russo e a versão popularizada no Brasil;
- Uma curiosidade relacionada à origem do prato.

Também é apresentada uma imagem relacionada ao strogonoff russo.

---

### 🎵 Página 3 — Formulário e mídias

A terceira página foi utilizada para demonstrar diferentes recursos do HTML5.

Nela foram adicionados elementos de formulário, como:

- Campo de data;
- Campo para envio de arquivo;
- Controle de volume utilizando `range`;
- Seletor de cores utilizando `color`.

Também foram adicionados recursos multimídia:

- Um vídeo com controles;
- Um áudio com controles;
- Uma legenda para o vídeo.

O vídeo utilizado apresenta um cachorro.

---
